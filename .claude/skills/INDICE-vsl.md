# Proyecto 03: VSL Closer

Cada .zip es una skill. Súbelas en Configuración → Capacidades → Skills.

## Guion VSL
- **vsl-scriptwriter**: Escribe, reescribe o audita guiones de VSL para cualquier producto, servicio o curso (hook, historia, mecanismo, oferta, CTA) con principios de Hormozi y psicología del comprador. Fuente (MIT): github.com/ai-saas-wizard/vsl-scriptwriter

## VSL Demo Software
- **video-sales-letter**: VSLs donde la demostración del producto carga el argumento, ideal para software y productos digitales, incluye videos cortos de upsell (OTO). Fuente (MIT): github.com/bertrand-do/video-sales-letter
