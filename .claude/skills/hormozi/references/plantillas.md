# Plantillas de salida

## Oferta completa

```
OFERTA: [Nombre MAGIC]
PARA: [cliente específico]  ·  NO ES PARA: [quién no]
RESULTADO SOÑADO: [en palabras del cliente]

PROBLEMAS → SOLUCIONES
1. [problema] → [solución] ([vehículo: DIY / DWY / DFY])
...

PILA DE VALOR
- [Componente]: [qué resuelve] — valor $[X]
- Bono: [nombre] — resuelve [objeción] — valor $[X]
VALOR TOTAL: $[X]   ·   PRECIO: $[X]

GARANTÍA: [tipo + texto]
ESCASEZ / URGENCIA (solo reales): [...]
TRIUNFO RÁPIDO (primeros días): [...]
```

## Auditoría rápida

```
ECUACIÓN DE VALOR (1–10)
- Resultado soñado: [n] — [por qué]
- Probabilidad percibida: [n] — [por qué]
- Tiempo hasta el resultado: [n] — [por qué]
- Esfuerzo: [n] — [por qué]

LOS 3 ARREGLOS DE MAYOR IMPACTO
1. [cambio concreto]
2. ...
3. ...

REESCRITURA
Titular: ...
Oferta: ...
Llamada a la acción: ...
```

## Plan de captación

```
CANAL PRINCIPAL: [uno de los cuatro]  ·  POR QUÉ: [...]
OFERTA DE ENTRADA / LEAD MAGNET: [...]
MENSAJE O GANCHO (3 variantes): ...
VOLUMEN DIARIO: [acciones o presupuesto]
DESTINO DEL CLIC: [WhatsApp / formulario / página]
MÉTRICAS: costo por lead, % que agenda, % que cierra, costo por cliente
REGLA DE DECISIÓN: [cuándo apagar, cuándo escalar]
```

## Modelo de dinero

```
ATRACCIÓN: [oferta] — $[X]
UPSELL: [oferta] — $[X] — [momento]
DOWNSELL: [oferta] — $[X] — [para quién]
CONTINUIDAD: [oferta] — $[X]/mes
CAJA EN 30 DÍAS POR CLIENTE: $[X]  vs  CAC: $[X]
```

## Guion de cierre

```
C: [pregunta de apertura]
L: [cómo etiquetar el problema]
O: [qué preguntar del pasado]
S: [3 puntos del resultado]
E: [5 objeciones probables + respuesta]
R: [mensaje de bienvenida y primer paso]
```
